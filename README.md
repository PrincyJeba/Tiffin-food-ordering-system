# Tiffin – Food Ordering System

A simple web-based food ordering application that allows users to browse food items, add items to a cart, and place orders.

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Docker
- GitHub Actions
- Google Artifact Registry
- Google Cloud Run
- Google Cloud Logging
- Google Cloud Monitoring

## DevOps Workflow

GitHub → GitHub Actions → Docker → Artifact Registry → Cloud Run

The project also demonstrates automated deployment, application monitoring, logging, failure detection, and recovery.
